Attention Tracking Benchmark

Standalone browser-based tool for measuring line-selection accuracy, calibration success, detection availability, and jitter of the current head + iris guidance pipeline.

Tracking Settings

Procedure

  1. Load a multi-paragraph passage and start the camera.
  2. Click any sentence/line to set the target, or use Previous / Next Target.
  3. Run calibration (or press Alt+C to instant-recenter on the target line).
  4. Capture a trial after the line, paragraph, and sentence highlights stabilize.
